CONCEPT PAGE
12-20 lines: lead + a plain-words explanation (2-4 short sentences) + one table OR 2-4 cards + one small worked example + trap note + exam note (+ mnemonic only if natural). No collapse/steps/chips/stats unless really needed. Always explain the "why" in a sentence or two. Do not compress ideas into fragments or bullet-style shorthand.
Classes: cp-lead, cp-card (blue green amber red violet teal pink) in cp-grid (c2 c3 c4), cp-formula, cp-note (tip trap trick remember info exam good), cp-example, cp-mnemonic, cp-vs, cp-timeline, cp-fig, plain tables.
Emphasis: never cp-hl. Only <u>, <b>, (<i> sparingly). All text as real HTML text (never in images/SVG/CSS content); one complete sentence inside ONE element; translate="no" on pure formulas. No backticks or ${ inside html.
Facts true to the book. If something is old/wrong/changed, write the CORRECT/CURRENT version silently (no "updated/new" words on pages) and list it only in "changelog".

Explanation: plain text, no HTML, 2-4 simple full sentences, max 50 words: why the right option is correct, one easy way to remember it, and why the tempting wrong option fails. No abbreviations.
